## 1. OpenAI partners with Hacktron to probe its own systems

**OpenAI 携手 Hacktron：外部红队重点测自家系统与第三方接口**

OpenAI 宣布与安全公司 Hacktron 合作，由双方工程师共同选定高优先级测试范围，重点检查其系统与第三方服务的连接方式；同时通过 Daybreak Red 扩大 Hacktron 对前沿模型的访问。Hacktron 以代码审查、渗透测试和红队用的 AI 智能体见长，双方最初因漏洞赏金计划结识。OpenAI 称，在加速用前沿模型做网络防御的同时，也要用同样的紧迫感找补自身漏洞。

Source: https://openai.com/index/partnering-with-hacktron

## 2. Anthropic presses ahead with a pre-Thanksgiving IPO at a lower valuation

**Anthropic 仍计划感恩节前 IPO，估值预期下调至约 1.25–1.75 万亿美元**

据《金融时报》援引多名投资者消息，Anthropic 仍拟在感恩节前上市，募资约 800–1000 亿美元，估值区间约 1.25–1.75 万亿美元：高于当前约 9650 亿美元的私募估值，但低于部分投资人此前期待的约 2 万亿美元。年化营收约 810 亿美元，较 7 月底的约 650 亿美元上升。中期选举后科技股抛售、数据中心监管预期趋紧，AI 公司融资与上市定价都更谨慎。

Source: https://the-decoder.com/anthropic-pushes-ahead-with-pre-thanksgiving-ipo-despite-tech-selloff-accepts-lower-valuation/

## 3. Crusoe sells unfinished Wyoming data center project to Google

**Crusoe 将怀俄明未完工数据中心项目出售给 Google，Google 拟再投约 170 亿美元**

丹佛数据中心开发商 Crusoe 确认，已把东南怀俄明一处未完工项目出售给 Google；此前 Crusoe 未能把 Google 做成该项目客户，外界亦传 Google 对其造价与工期存疑。出售价格未披露，但 Google 宣布计划再投入约 170 亿美元建设园区。该项目最初与 Tallgrass 合作规划，远期规模曾设想至约 10 GW。尽管交出这块地，Crusoe 仍在为 Google 开发得州 Amarillo 附近的另一处数据中心。

Source: https://techcrunch.com/2026/11/06/crusoe-sells-troubled-wyoming-data-center-project-to-google/

## 4. Microsoft: attackers’ AI agents can go from GitHub secrets to cloud data in five minutes

**微软：攻击者用 AI 智能体扫 GitHub 泄露密钥，最快约 5 分钟打到云数据**

微软威胁情报观察到，攻击者使用名为 ARTEX 的进攻性 AI 智能体框架，在公开 GitHub 仓库中大规模检索凭证、应用密钥和推理 API Key，并能自动分析结果、继续对云资源下手。至少有一起案例中，智能体从扫描 GitHub 到从 Azure Key Vault 窃取数据只用了约 5 分钟；后续还出现用被盗应用凭证登录服务主体、枚举资源、访问存储与 SharePoint 等行为。微软提醒：公开暴露的密钥在轮换或吊销前都可被滥用，删掉仓库里的明文并不等于修复。

Source: https://www.microsoft.com/en-us/security/blog/2026/11/05/threat-actors-use-agentic-ai-tooling-to-find-and-abuse-exposed-secrets/

## 5. NVIDIA releases four Cosmos 3 Nano checkpoints for interactive world simulation

**英伟达开源四个 Cosmos 3 Nano 检查点，用于交互式世界仿真**

英伟达在 Cosmos 3 家族中新增大约 4 个开源权重检查点，均为 Cosmos 3 Nano 的后训练示例，各约 160 亿可训练参数，采用 OpenMDW 1.1 许可。Transfer-Auto 可生成最多 11 路摄像头及可选 RGB–LiDAR 的驾驶数据；Sim-Auto 能流式输出同步的相机与激光雷达观测；Sim-Transfer 把物理仿真器的空间控制变成逼真视频；Sim-Bimanual 则根据双臂机器人或相机动作预测下一帧画面。面向自动驾驶与机器人的交互仿真与合成数据，而不是直接面向消费级聊天产品。

Source: https://huggingface.co/blog/nvidia/cosmos-interactive-world-simulation
