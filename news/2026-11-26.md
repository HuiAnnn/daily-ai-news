# Daily AI News — 2026-11-26

> Digest date: 2026-11-26 (Asia/Shanghai). Sources gathered from the past ~24–48 hours.

## 1. OpenAI starts merging ChatGPT Chat and Work usage limits

**OpenAI 开始向部分 Pro 用户推送 Chat 与 Work 合并体验：用量将共用额度，Instant 仍不计入；12 月更广范围上线**

OpenAI 已开始向一小部分 ChatGPT Pro 订阅用户推送将 Chat 与 Work 合并为统一体验的更新。产品负责人 Thibault “Tibo” Sottiaux 于周二在 X 上表示该推送已经启动。OpenAI 发言人对 TechCrunch 表示，在新的计费方式下，Chat 与 Work 将共用同一套用量额度；使用 Instant 模型的对话仍不计入共享额度，用户在用尽额度后也仍可继续使用 Instant。发言人同时表示，大多数用户预计不会比现在更频繁地等到额度重置，但一小部分使用最重的用户可能会更快触及上限。根据 OpenAI 帮助中心，Plus、Pro 与 Business 方案将在 12 月起把 ChatGPT 与 Codex 的用量合并计算，以便把 Work 的智能体能力并入主聊天体验；更广泛的共享额度计划于 12 月推出。

Source: https://techcrunch.com/2026/11/25/openai-says-heavy-chatgpt-users-may-hit-limits-sooner-as-it-merges-chat-and-work/

## 2. Anthropic migrates Messages API from Python to Rust

**Anthropic 将 Messages API 从 Python 迁至 Rust：在未停机、未冻结功能开发的情况下，单请求 CPU 约降 70%，中位首 token 时延约降 20%**

Anthropic 于 11 月 25 日发布研究文章，介绍其将 Messages API（客户以及 Claude Code、Cowork 等自家应用调用 Claude 的主要接口）从 Python 迁移到 Rust 的过程。官方称，自 2024 年初到 2026 年秋季，该 API 的流量约增长了 1800 倍；Claude 大约用一周写出了核心请求路径的第一版，但要验证 Rust 版本与线上 Python 服务行为一致并不容易：迁移期间 Python 服务仍在持续变更，模型回复本身也不确定，且团队无法直接查看客户请求。为此，他们把线上 Messages API 本身变成校验器，用生产流量对比差异，并自动调度智能体修复不一致之处。Anthropic 表示，最终上线的 Rust 版 API 将每请求 CPU 使用量降低约 70%，并将中位首 token 时延缩短约 20%，全过程没有停机，也没有冻结功能开发。

Source: https://www.anthropic.com/research/migrating-api-to-rust

## 3. FCC authorizes SpaceX to deploy up to 1 million Starmind satellites

**美国联邦通信委员会批准 SpaceX「Starmind」计划：最多部署 100 万颗搭载 AI 芯片的轨道数据中心卫星**

美国联邦通信委员会（FCC）于 11 月 25 日宣布，授权 SpaceX 在其「Starmind」计划下最多部署 100 万颗搭载 AI 芯片的卫星。The Verge 报道称，这是该机构首次批准完整的 AI 卫星星座；批准要求 SpaceX 最迟在 2033 年部署至少一颗卫星，并在 2040 年前达到 100 万颗的规模。FCC 同时暂缓了 SpaceX 关于将轨道高于 600 公里的卫星送入「坟场轨道」、而不是让其在大气层烧毁的处置申请，理由是公司尚未提供足够的处置方案信息。SpaceX 将 Starmind 描述为在太空收集太阳能、为地面 AI 能力供电的方案，并称将通过连接 Starlink 的高速激光把数据传回地球；公司还计划在即将建设的 Terafab 工厂生产卫星所用芯片。

Source: https://www.theverge.com/science/1042278/spacex-fcc-starmind-ai-space-data-centers

## 4. New York signs five-year ban on AI chatbot toys

**纽约州州长霍楚签署法案：五年内禁止在该州制造、经销和销售内置 AI 聊天机器人的玩具**

纽约州州长 Kathy Hochul 于 11 月 24 日签署 S.9408A/A.11144B 法案，对内置或集成 AI 聊天机器人的玩具设立为期五年的暂停措施，覆盖会联网、可与儿童对话的毛绒玩具、娃娃和机器人等。该法将在签署 90 天后生效，由纽约州司法部长执法，违规者可能面临每项违规每天最高 1.5 万美元的民事罚款。官方声明提到，有消费者组织对面向 3 至 12 岁儿童销售的聊天机器人玩具进行测试，发现部分玩具会深入讨论露骨话题、较少或没有家长控制，且安全限制会随对话延长而减弱；部分玩具还可能录下孩子的声音或扫描面部。由于该暂停措施赶不上本季假日购物，霍楚同时呼吁家长和看护人在选购节日礼物前，留意玩具是否包含 AI 伴侣、会收集哪些信息，以及能否与孩子进行开放式对话。

Source: https://www.governor.ny.gov/news/consumers-begin-their-holiday-shopping-season-governor-hochul-signs-five-year-ban-ai-chatbot

## 5. State AGs challenge Character.AI plan to auction private chats

**42 名州检察长反对 Character.AI 破产拍卖用户私密对话：涉及逾 2100 万美国账户，其中逾 210 万为未成年人账户**

据 TechCrunch 11 月 25 日报道，一个由 42 名州检察长组成的联盟正在介入 Character.AI 的破产程序，试图阻止该公司出售敏感用户数据。加州司法部长 Rob Bonta 等发布的声明称，拟于 2026 年 12 月 1 日拍卖的数据包含逾 2100 万个美国账户的聊天记录，其中逾 210 万个账户注册为未成年人，同时还涉及 IP 地址等个人数据。目前已披露的唯一匿名竞标方是 11 月 13 日在特拉华州成立的 Smirks and Pangs Acquisition LLC；次日 Character.AI 将其定为拍卖底价竞标方。检察长们认为，拟议交易未对买方施加保护用户的义务：买方不必遵守 Character.AI 的隐私政策，也不必尊重用户的退出或删除请求，甚至可以再次转售数据。联盟要求法院拒绝拟议出售条款、否定该公司作为首席竞标方及其 35 万美元「分手费」；至少应将儿童对话和其他敏感数据排除在出售范围之外。Character.AI 于 10 月申请了第 11 章破产保护，并曾向用户表示不会出售个人信息。

Source: https://techcrunch.com/2026/11/25/state-ags-fight-character-ais-plan-to-auction-off-users-private-chats/
