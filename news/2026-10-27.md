# Daily AI News — 2026-10-27

> Digest date: 2026-10-27 (Asia/Shanghai). Sources gathered from the past ~24–48 hours.

## 1. OpenAI launches GPT-6.1 Terra for cheaper computer use

**OpenAI 发布 GPT-6.1 Terra：计算机操控更强，API 价格腰斩**

OpenAI 推出面向视觉理解与桌面操作的 GPT-6.1 Terra，主打读写屏幕、填表、剪辑等日常电脑任务。标准 API 定价为每百万 token 输入 \$1、输出 \$5，约为 GPT-5.6 Terra / GPT-6.1 Sol 的一半；ChatGPT Work、Codex 与 API（`gpt-6.1-terra`）已对 Plus/Pro/Enterprise/Edu 开放。公司称 Agents’ Last Exam 中等推理下比前代高约 15 个百分点，Terminal-Bench 4.0 最高推理正确率从 21.5% 升至 50.3%，低推理幻觉率从 53.6% 降至 16.7%。

Source: https://openai.com/index/introducing-gpt-6-1-terra

## 2. OpenAI announces AI research results with academic shepherds

**OpenAI 公布三项 AI 科研结果，并试点「学术牧羊人」协作发布**

OpenAI 于 10 月 26 日宣布，其模型在调和分析（local smoothing / Kakeya）、复杂度（证伪 Exponential Time Hypothesis）与量子场论（含 QCD / Yang–Mills 存在性相关结果）上产出新证明，并以 Lean 等形式化。发布方式改为请外部专家当 shepherds：数学结果直接公开 AI 产出；计算机科学由 Impagliazzo、Paturi、Williams 等组队解释并同步公开材料；物理由 David Gross 等组队，暂缓公开原始 AI 文稿。公司强调不争学术署名，协作独立、自愿、无偿。

Source: https://openai.com/index/building-scientific-understanding-with-academic-communities/

## 3. Anthropic files S-1 for proposed IPO under ticker ANT

**Anthropic 向 SEC 提交 S-1，拟以「ANT」登陆纳斯达克**

Anthropic, PBC 于 10 月 26 日提交 Form S-1，拟发行 Class A 普通股并申请在 Nasdaq Global Select Market 以代码「ANT」上市；发行股数与价格区间尚未确定。公司为特拉华公益公司（public benefit corporation），治理上仍保留 Long-Term Benefit Trust 的 Class T 董事席位与创始人 Class F 超级投票权等结构。今日公告本身不构成要约，登记声明生效前不得出售相关证券。

Source: https://www.anthropic.com/news/s1-sec

## 4. Meta launches up to $95B equity plan for AI build-out

**Meta 启动最高约 950 亿美元股权融资计划，加码 AI 基建与超级智能**

Meta 于 10 月 26 日宣布融资计划：先进行约 350 亿美元承销公开发行（约 225 亿 Class A 普通股 + 约 125 亿强制可转优先股存托凭证），并计划在 Class C 开始交易后启动约 600 亿美元 ATM 计划。公告称资金用于 AI 基础设施与 personal superintelligence 等方向；Nvidia、AMD、Broadcom 等对认购最多约 50 亿美元 Class A 表示兴趣。

## 5. OpenAI frontier models coming to Google Cloud Model Garden

**OpenAI 模型将进入 Google Cloud Model Garden，企业可走 GCP 账单采购**

OpenAI 与 Google Cloud 合作，计划把前沿模型与 Codex agent 工作流接入 Model Garden，并通过 Google Cloud Marketplace 交易；有 GCP 消费承诺的企业可用承诺额度抵扣。双方称后续还将出现在 Google Antigravity 与 Gemini Agent 中，以便企业按任务选模型；全面可用预计数周内，微软仍是 OpenAI 主要云合作伙伴。

Source: https://openai.com/index/openai-models-google-cloud
