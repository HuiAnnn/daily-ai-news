## 1. Microsoft launches Guardian Agents, treating AI agents like insider threats

**微软推出 Guardian Agents：把企业里的 AI Agent 当「内部威胁」来盯**

微软在 Project Perception 中新增 Guardian Agents，用于监控企业部署的 AI Agent；Defender 还能识别员工自带的约 60 类 Agent（如 Claude Code、Codex），并按任务动态收紧权限、在高风险操作时要求人工批准。Nadella 此前撰文主张「把智能的供给与对它的授权分开」，不应只依赖模型厂商的安全承诺。

Source: https://techcrunch.com/2026/10/19/microsoft-says-ai-agents-are-like-insider-threats-as-frontier-models-cant-be-trusted/

## 2. OpenCode Console breach runs up charges on users' AI accounts

**开源编程 Agent OpenCode 的 Console 遭入侵，用户 API Key 被盗刷**

OpenCode 称旧系统被攻破，约 1.4% 的 OpenCode Console 用户受影响，存放在工作区的 API Key 遭滥用，有人账单达数百乃至上千美元。Anthropic 和 Google 已封禁疑似泄露的 Key，OpenAI 表示将退还被盗用额度；开源客户端和 CLI 本身不受影响，公司建议用户到各家平台吊销并更换 Key。

Source: https://techcrunch.com/2026/10/19/hackers-hit-ai-coding-tool-opencode-running-up-charges-on-users-ai-accounts/

## 3. OpenAI improves coding in COBOL, Fortran and other low-resource languages

**OpenAI 新模型大幅提升 COBOL、Fortran 等「冷门语言」编程与迁移能力**

OpenAI 发布两项评测：MultiLangBench 上 GPT-6 Astra 在 20 种语言的平均通过率达 87.4%（GPT-5.6 Sol 为 26.8%）；COBOL 迁移评测中 GPT-6.1 Sol 低推理档准确率 86.6%、高推理档 97.9%，成本还低 39%。瞄准银行、气象等依赖老旧系统的企业现代化需求。

Source: https://openai.com/index/low-resource-programming-languages/

## 4. AI assistant startup Town hits unicorn valuation four months after launch

**企业 AI 助理 Town 上线四个月即成独角兽，B 轮融资 1.08 亿美元**

前 Plaid CTO 创办的 Town 为每位员工配一个连接邮件、日历与业务系统的 AI 助理「Townie」，助理之间可共享经批准的信息，现也能对接外部客户。B 轮由 Forerunner 与 Menlo 领投，公司称上线数周 ARR 即达数百万美元，同时推出可自动同步业务信息的共享工作流。

Source: https://techcrunch.com/2026/10/19/ai-assistant-startup-town-nabs-unicorn-valuation-four-months-after-launch/

## 5. Anthropic and Nscale reportedly near another $45B compute deal

Source: https://techcrunch.com/2026/10/19/nscale-and-anthropic-are-reportedly-in-talks-for-yet-another-45-billion-compute-deal/
