## 1. Nvidia pauses server shipments to Southeast Asia

**英伟达暂停向马来西亚、新加坡、泰国和印度尼西亚发运服务器：评估区域合作伙伴是否符合美国出口管制要求**

据 TechCrunch 11 月 26 日报道，华尔街日报称英伟达已要求戴尔、Super Micro 等制造合作伙伴，暂停向马来西亚、新加坡、泰国和印度尼西亚发运服务器，暂停期尚未明确。英伟达此举是为了评估区域合作伙伴是否满足美国出口管制要求。报道指出，中国企业一直通过当地数据中心远程调用英伟达芯片；美国商务部本月早些时候关闭了这一漏洞。智库 Institute for Progress 估计，此类远程数据中心提供了约 24% 的中国人工智能算力。

Source: https://techcrunch.com/2026/11/26/nvidia-hits-pause-on-chip-shipments-to-southeast-asia/

## 2. Google makes Workspace MCP servers and CLI generally available

**Google 宣布 Workspace MCP 服务器与官方 CLI 正式可用：自 2027 年 2 月 1 日起，AI 代理须经 MCP 或 CLI 访问 Workspace，不得直接调用 REST API**

Google 于 11 月 24 日宣布，由 Google 托管的 Workspace MCP 服务器和官方 Workspace CLI 正式推出，覆盖 Gmail、Drive、Docs、Sheets、Slides、Calendar、Chat 和 Tasks（Keep 即将加入），并同步推出标准化用量档位、Workspace AI Tools 附录及更完善的企业管控。官方称，AI 代理或类似访问工具必须通过 MCP 服务器或 Workspace CLI 访问 Workspace 数据，而不能直接调用 REST API，技术强制将于 2027 年 2 月 1 日开始。用量分为免费的 Standard 档和面向更高配额的 Scaled 档（先覆盖 Gmail、Drive 和 Calendar）；自 2027 年 4 月 1 日起，选择 Scaled 档的项目仅对超出每日免费额度的 API 或 MCP 用量收费，若未采取行动，项目可能被限制到已公布的配额。Google 表示，目前超过 99% 的活跃开发者处于 Standard 档，可继续免费使用；管理员还可设置需用户确认的敏感操作，并沿用现有 DLP 与审计日志。

Source: https://workspaceupdates.googleblog.com/2026/11/mcp-servers-cli-standardized-usage-tiers-now-available.html

## 3. OpenAI starts testing Private Inference with select customers

**OpenAI 开始向少数企业客户试测 Private Inference：用机密计算保护提示词与回复在推理过程中不被查看**

据 The Next Web 11 月 25 日报道，OpenAI 已开始向一小部分企业客户测试 Private Inference。该功能目前为 alpha，属于 Private Intelligence 方案的一部分，利用机密计算和「严格、可验证的控制」，保护企业提示词与回复在模型处理期间的隐私。OpenAI CEO Sam Altman 于周三在 X 上宣布了这一试验，并表示更强的隐私保护将让前沿 AI 能用于更多工作，企业隐私对健康的生态也很重要。该功能曾在 DevDay 上作为预览展示。OpenAI 相关负责人 Shekar 称此次测试只是第一步，公司正在筹备更多算力以支持更大规模推广，但未给出时间表。Private Intelligence 中的另一项能力 Private Safety Processing 已于 9 月开始推送。

Source: https://thenextweb.com/news/openai-private-inference-testing-customers

## 4. Anthropic lets Claude artifacts install as Mac and Windows apps

**Anthropic 在 Claude 桌面端推出「Install as app」测试：可将 Artifact 安装为 macOS 与 Windows 独立应用**

Anthropic 宣布，Claude for Mac 和 Windows 开始以测试版推送「Install as app」功能：用户可以把常用 Artifact 安装成带有独立图标和窗口的桌面应用，而不必再在 Claude 里打开。安装后的应用可使用 Claude 与用户的连接器，并在底层 Artifact 被编辑后自动更新；向 Claude 发起的请求计入所属方案的用量。应用在与电脑交互前需获得许可，权限分三档：默认仅相当于浏览器能力；应用权限可申请置顶窗口、全局快捷键和通知等；完全访问则可在不再逐次询问的情况下运行程序、读写或删除文件。完全访问仅适用于用户自己制作的应用，或 Team / Enterprise 组织内成员制作的应用；权限只覆盖当前版本，应用更新后会再次征求授权。该功能正在所有方案中以测试版推送，HIPAA 就绪组织和混合部署暂不可用；Team 默认开启但关闭完全访问，Enterprise 需所有者打开后才可用。Claude Docs、Slides 和 Sheets 等 Artifact 目前无法安装。用户更新客户端后，可在 Share 菜单中选择「Install as app」，无需自行打包或签名。

Source: https://claude.com/resources/articles/install-as-app

## 5. Volvo Cars trains Hexagon AEON humanoids at Ghent plant

**沃尔沃汽车在比利时根特工厂训练 Hexagon Robotics 的 AEON 人形机器人，计划 2027 年中期投入实际生产**

沃尔沃汽车 11 月 26 日宣布，正在比利时根特工厂引入并训练 Hexagon Robotics 的 AEON 人形机器人，在真实工业任务上做验证，目标是协助员工完成重复性、人体工学负担较重的工作。根特是沃尔沃汽车首个尝试人形机器人的工厂。公司团队与瑞典 Hexagon 集团机器人部门合作，采用模仿学习：机器人通过仿照人工操作掌握任务，首个任务是将零部件高精度放入两个夹具。任务验证后，训练将逐步扩展到处理多种零件、在产线上移动，以及与工厂自动化系统交互。AEON 高 1.65 米、重 60 公斤，依靠摄像头与传感器感知环境；它以轮式移动而非双足行走，时速可达 2.4 米/秒，负载 10 公斤。沃尔沃汽车首席制造官 Magnus Nilsson 表示，人形设计让 AEON 能融入现有产线和团队，承担部分体力负担最重的工作。此次训练将为 2027 年上半年的工厂试点做准备，届时会有更多 AEON 抵达根特，目标是自 2027 年中期起用于实际生产。

Source: https://www.volvocars.com/uk/media/press-releases/5B712552CE36E240/
