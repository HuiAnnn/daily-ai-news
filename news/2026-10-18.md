# Daily AI News — 2026-10-18

> Digest date: 2026-10-18 (Asia/Shanghai). Sources gathered from the past ~24–48 hours.

## 1. DeepSeek ships V4.1-Flash-1017 and opens Search & Fetch APIs

**DeepSeek 上线 V4.1-Flash-1017，并对开发者开放自研 Search & Fetch API**

DeepSeek 将 Web/App/API 上的 Flash 升级为 DeepSeek-V4.1-Flash-1017，沿用 `deepseek-flash` 模型名与既有计价，宣称基准更高、任务完成更快、输出更短。同日开放面向 Agent/RAG 的 Search 与 Fetch 独立接口（同密钥、按次计费约 $0.75/千次成功调用），由自研搜索引擎支撑；文档称服务端工具调用将于北京时间 11 月 1 日前后结束免费期。

Source: https://api-docs.deepseek.com/

## 2. Meta launches Muse Wonder and Muse Wonder Full

**Meta 发布 Muse Wonder / Wonder Full：面向 Agent 与编程工作流的前沿模型**

Meta Superintelligence Labs 推出面向长程 Agent、编程与电脑使用的 Muse Wonder 与更强的 Muse Wonder Full。Wonder 可走 Meta Model API 与 Muse Code，API 标价约 $4/$20（输入/输出百万 token）；Wonder Full 暂仅限 Muse Code 的 Power / Maximum 订阅档，未开放按量 API。独立评测称 Wonder Full 在 Artificial Analysis Intelligence Index 上约 56 分。

Source: https://dev.meta.ai/resources/blog/build-with-muse-wonder

## 3. OpenAI opens Rosalind Academic Plan for US labs

**OpenAI 推出 Rosalind Academic Plan：美高校实验室可申请免费席位与 GPT-Rosalind**

OpenAI 面向美国高校研究实验室开放 Rosalind Academic Plan：获批后最多可获约 30 个 ChatGPT Business Standard 席位（至多 12 个月免费），并在 trusted-access 通过后使用生命科学向模型 GPT-Rosalind；含 ChatGPT/Codex，不含 API 额度。需由 PI 或实验室负责人申请，并完成机构与 biosafety 相关审核。

Source: https://openai.com/index/introducing-the-rosalind-academic-plan/

## 4. Anthropic gives METR employee-like evaluator access

**Anthropic 向 METR 开放「类员工」级独立评估权限，结果可公开发布**

Anthropic 宣布为非营利评估组织 METR 的 6 名成员提供接近其内部风险团队的硬件、工位与工具权限，以落实第三方独立评估承诺。METR 可发布风险评估结论；Anthropic 无否决权，仅能在客户数据、律师特权、模型架构等窄范围要求脱敏，且 METR 可公开评论脱敏是否合理。另称与 SecureBio、Accenture 等亦有不同层级合作。

Source: https://www.anthropic.com/news/an-update-on-independent-evaluators

## 5. Mistral releases Timestral time-series models

**Mistral 发布 Timestral：首个时序预测基础模型家族**

Mistral 推出 Timestral 1.0，面向零样本、概率性多变量时序预测，提供约 5M–209M 四档参数量，支持协变量与分位数输出，可在 CPU 上运行。官方称最大规格在 GIFT-Eval、TIME、fev-bench 等零样本榜单上表现靠前，补齐其在「非文本/对话」垂直模型产品线。

Source: https://mistral.ai/news/timestral/
