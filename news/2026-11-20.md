## 1. Anthropic jumps 17% in Nasdaq debut, closes at $97.17

**Anthropic 登陆纳斯达克首日收涨 17%，收盘价 97.17 美元，完全稀释市值约 1.8 万亿美元**

Anthropic 于 11 月 19 日以代码「ANT」登陆纳斯达克。据 CNBC 报道，股票开盘价为 111.50 美元，较 83 美元的发行价高出 34%；收盘报 97.17 美元，较发行价上涨 17%。按收盘价计算，公司完全稀释市值约 1.8 万亿美元，位列美国上市公司第七，仅次于苹果、微软、英伟达、Alphabet、亚马逊和 SpaceX。此次 IPO 共发行 9.8 亿股、募资 813 亿美元；首日成交量超过 8.46 亿股，高于 SpaceX 上市首日的 5.22 亿股。

## 2. Google adds computer use to the Gemini app for Mac

**谷歌为 Mac 版 Gemini 应用加入电脑操控：可在后台跨本地文件、桌面应用和网页完成多步任务**

谷歌于 11 月 19 日宣布，Mac 版 Gemini 应用新增 computer use（电脑操控）功能。用户用自然语言描述要做的事，Gemini 即可在本地文件、桌面应用和网页之间点击、输入、打开菜单并填写表单。它在隔离的后台窗口中运行，聊天里可看实时预览，主屏幕和光标仍可自由使用；用户可选择授权哪些应用、随时暂停，并在关键操作前确认。该功能目前以英语在美国向 18 岁以上个人 Google 账号的 Google AI Plus、Pro 和 Ultra 用户推送，需搭载 Apple 芯片、运行 macOS Sequoia 15.0 或更高版本的 Mac。

Source: https://blog.google/innovation-and-ai/products/gemini-app/computer-use-mac/

## 3. OpenAI releases GPT-Live-1.1 in the API

**OpenAI 在 API 中推出 GPT-Live-1.1，并新增 Standby 待机计费，降低语音会话空闲成本**

OpenAI 于 11 月 19 日在 API 更新日志中宣布推出 GPT-Live-1.1。官方称，该模型在多语言语音对话中改进了发音、口音一致性和转写效果；开发者可在现有 Live 会话配置中改用 `gpt-live-1.1`，并用自然语言说明何时把任务交给后端处理。与此同时，GPT-Live-1 与 GPT-Live-1.1 的 WebRTC 会话可配置 standby（待机）：在空闲时暂停推理，有人开口后再恢复，以降低闲置成本。该模型通过 `v1/live/sessions` 接口提供。

Source: https://developers.openai.com/api/docs/changelog

## 4. Google previews Tool Retrieval in the Gemini API

**Gemini API 预览上线 Tool Retrieval：按需加载工具参数，降低多工具 Agent 的输入成本**

谷歌于 11 月 19 日宣布，Tool Retrieval（工具检索）已在 Gemini Interactions API 中进入预览。当 Agent 接入几十甚至上百个工具时，每次请求都发送完整参数 schema 会推高输入 token、增加延迟，并可能降低选工具的准确度。开启后，开发者添加 `tool_search` 工具，并为希望延后加载的工具设置 `defer_loading: true`；模型仍能看到这些工具的名称和描述，但参数 schema 会在真正需要时按名称加载，且都在同一次请求内完成。该功能也可用于远程 MCP 服务器，并与前缀缓存兼容。官方称不另收费，按所用模型的标准 token 价格计费，适用于 Gemini 3.6 及之后的模型（含全部 Gemini 4）。

Source: https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tool-retrieval/

## 5. Apple may be building its own Mac AI agent

**苹果疑似自研可操控电脑的 AI Agent，彭博称最早或于 2027 年底推出，尚处早期**

TechCrunch 11 月 19 日援引彭博报道称，苹果近日发布了一则高级工程经理职位，负责打造「能使用电脑的 AI Agent」。招聘启事写道，该 Agent 应能像能干的人一样使用电脑：浏览网页、跨应用操作、运行命令、编写和调试代码、调用服务，并在每一步选择合适的工具，同时保持私密和苹果一贯的完成度；它还需要能在应用、浏览器、命令行、代码和 API 之间流畅完成多步任务。TechCrunch 向苹果求证未获回复。彭博同时提到，苹果一边推进自有助手，一边在即将到来的 macOS 27.3 中加强对第三方 Agent 获取完整系统权限的限制；公司曾考虑最早于明年年底推出该服务，但进展仍处于早期阶段。

Source: https://techcrunch.com/2026/11/19/apple-may-be-developing-its-own-ai-agent-that-runs-your-mac/
