# Daily AI News — 2026-11-05

> Digest date: 2026-11-05 (Asia/Shanghai). Sources gathered from the past ~24–48 hours.

## 1. OpenAI to acquire Pierre for Codex Git tooling

**OpenAI 收购 Pierre：把 Code Storage / Diffs 等 Git 工具并进 Codex**

OpenAI 宣布将收购 Pierre Computer Company（Code Storage 与 Trees、Diffs、Highlights 等开源开发者工具背后的公司）。Codex 应用里的文件浏览与变更审阅已在用 Pierre 的库；交割后拟把 Code Storage 能力并入 Codex，开源项目继续开源。交易仍需监管批准，此前 OpenAI 刚披露自研 Git 后端 Pando。这是在「写代码的模型」之外，补「存代码、审代码」的基础设施。

Source: https://openai.com/index/openai-to-acquire-pierre/

## 2. OpenAI ships Images 2.6 with native GIF creation

**OpenAI 推出 Images 2.6：ChatGPT 可原生生成并编辑 GIF**

OpenAI 在 ChatGPT、Codex 与 API 上线 Images 2.6：支持用提示词或上传照片直接生成 GIF，可调播放速度、逐帧编辑；官方称生成速度约快 50%，API 提供 Flare（更快）与 Sunburst（更高质量/一致性）两档。全订阅档位已全球可用；公司称每周经 ChatGPT/API 生成图片超 40 亿张。图像能力从静态图延伸到短动效，创作者与营销场景门槛再降一截。

Source: https://openai.com/index/introducing-images-2-6/

## 3. Google DeepMind: Antigravity Cheminformatics Skills

**DeepMind：Antigravity 化学信息学 Skills，药物发现工作流压缩到约一小时**

Google DeepMind 发布面向 Google Antigravity 的 Cheminformatics Skills：以肺癌靶点案例演示，智能体可检索数千化合物、做匹配分子对分析并提出刚性化大环候选与合成路线，整段流程约一小时（传统常需数日）。底层接 RDKit、ChEMBL、PubChem 等确定性化学工具；企业用户与应用者可试用，另有面向科研人员的用量补贴计划。定位是加速假设生成，实验验证仍不可省。

Source: https://deepmind.google/blog/agentic-cheminformatics-with-google-antigravity/

## 4. Google backstops ~$19B Anthropic leases at TeraWulf

**Google 为 Anthropic 约 190 亿美元数据中心租约提供信用背书**

TeraWulf 宣布与 Google 签署信贷支持协议，覆盖肯塔基州 Justified 园区 Anthropic 约 401MW、约 20 年、合计约 190 亿美元的合约租约；同期与 Fluor 签下确定性 EPC。若 Anthropic 违约或破产，Google 可代付租金并接手租约，或在特定情形支付终止费并获股权。背书自各楼栋末个机房启用起生效。云厂商以信用与算力绑定「客户」Anthropic 的基础设施融资，竞争边界更像资本结构博弈。

Source: https://investors.terawulf.com/news-events/press-releases/detail/148/terawulf-secures-google-credit-backstop-for-project-financing-in-support-of-19-billion-anthropic-lease-executes-definitive-fluor-epc-agreement

## 5. Nothing teases screen-free AI-native device for December

**Nothing 预告无屏幕「AI 原生」硬件，12 月出货**

The Verge 报道，Nothing CEO Carl Pei 在 X 发帖称首款 AI 原生产品将于下月发货：无新屏幕、「不可能只是个 App」，并配暧昧产品剪影。此前有传闻称公司在做 AI 眼镜等配件，并自称向 AI 优先转型。无屏 AI 硬件赛道已有 Humane Pin、Friend 等先例，成败仍看场景与续航，而非「再做一个挂件」。

Source: https://www.theverge.com/ai-artificial-intelligence/1026586/nothing-screen-free-ai-device-carl-pei
