## 1. OpenAI raises ~$11B at $1.25T valuation

**OpenAI 新一轮融资约 110 亿美元，估值约 1.25 万亿美元**

据 Bloomberg 消息，OpenAI 新一轮融资已拿到约 110 亿美元，公司估值约 1.25 万亿美元；整轮尚未关账，后续或合计约 200 亿美元，远低于此前约 300 亿美元的目标。同日市场亦传 Anthropic IPO 潜在买方对其估值预期下调。中期选举后数据中心与监管情绪趋紧，AI 巨头融资与上市节奏都更敏感。

## 2. OpenAI launches BioBasicsBench for wet-lab agents

**OpenAI 发布 BioBasicsBench：测 AI 读湿实验原始数据的能力**

OpenAI 与酶设计公司 Ligo 推出 BioBasicsBench：100 道日常湿实验任务，覆盖凝胶、菌落平板、显微、测序与仪器导出等原始证据，重点考察读图、找错、判断证据是否够支撑结论。在 xhigh 推理设置下，GPT-6 Astra 均分约 66.7%，高于 GPT-5.6 Sol 的 43.8%；官方强调分数上升还不等于能在实验室可靠做判断。

Source: https://openai.com/index/measuring-how-ai-agents-handle-wet-lab-science

## 3. GitHub Copilot code review gains API management

**GitHub Copilot 代码审查：企业到仓库可用 API 管配置，总览更紧凑**

GitHub 更新 Copilot code review：可用 REST/GraphQL 从企业策略管到单个仓库（开关、默认 effort、runner、自定义指令与 MCP 等）；审查总览更紧凑，失败会自动重试一次。面向 Copilot Pro 到 Enterprise；企业/组织级设置端点暂不支持 GitHub App 与 fine-grained PAT。

Source: https://github.blog/changelog/2026-11-06-copilot-code-review-api-management-and-review-overview-updates/

## 4. METR: Anthropic R&D roughly 2× faster

**METR：Anthropic 能力进步速度约达此前两倍，主因或是 AI 辅助研发**

独立评估组织 METR 在 Anthropic 做高权限评估后称：截至 2026 年 10 月，Anthropic 在可良好定义任务上的能力提升速度，大约是 2024 年 3 月至 2025 年 10 月的两倍（不确定性大，1.3×–3× 都可能）；AECI 自 2025 年 10 月起增速约 1.9×。报告认为加速主要不是训练算力放大，且多数可能来自 AI 辅助研发；大量证据被 Anthropic 以机密为由涂黑。

Source: https://metr.org/blog/2026-11-05-anthropic-ai-rd-acceleration-assessment/

## 5. Meta Muse adds custom “spaces”

**Meta Muse 上线 Spaces：用一句话定制类 App 体验，可接外部应用数据**

Meta 为 Muse 推出 Spaces：用户用自然语言描述需求（购物汇总、课表看板、音乐追踪等），即可生成可放侧栏或主 Tab 的类 App 体验，并可同步 Gmail、Notion 等外部应用的实时数据，还能按时间表唤起。功能随 Muse 可用地区推出；分享与协作仍在探索。Agent 产品形态从「聊天」进一步走向「可常驻的个人小工具」。

Source: https://about.fb.com/news/2026/11/introducing-spaces-customize-muse-app/
