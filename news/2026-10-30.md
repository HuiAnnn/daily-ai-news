# Daily AI News — 2026-10-30

> Digest date: 2026-10-30 (Asia/Shanghai). Sources gathered from the past ~24–48 hours.

## 1. Mistral releases open weights for Large 4 (Le Chonk)

**Mistral 开源 Large 4（Le Chonk）权重：万亿参数多模态旗舰**

Mistral 正式放出 Large 4 开源权重：约 1 万亿总参数、520 亿激活参数的原生多模态 MoE，主打 agentic coding 与防御性网络安全；官方称三周 RL 后在 FrontierCode、Terminal-Bench 等开源侧编码榜上领先或并列前列，并提供 low/medium/high 三档推理模式。权重可在 Hugging Face 自托管（vLLM / SGLang），API 定价约 $0.70/$2.10 每百万输入/输出 token；MaaS 商用需另签商业许可。

Source: https://mistral.ai/news/mistral-large-4-oss/

## 2. OpenAI updates Model Spec around five core values

**OpenAI 更新 Model Spec：行为规范改按五大价值观重组**

OpenAI 于 10 月 29 日更新公开的 Model Spec，将指引围绕「忠实于人类意图、伤害最小化、诚实透明、人类自主、关怀」五条价值观重组；新增对上下文、监督与自主性的说明，调整部分默认行为，并大幅删减细粒度文风规则，文档中改称模型为「GPT」而非「assistant」。同日还发布了前沿模型错位行为监测体系说明。

Source: https://openai.com/index/updated-model-spec

## 3. GitHub Copilot Fusion generally available

**GitHub Copilot Fusion 正式上线：按任务自动路由与编排多模型**

GitHub 宣布 Copilot Fusion 全面可用：开发者选 Standard / High / Max 档位后，系统按任务自动选模并走 Single、Cascade 或 Critique 编排。官方称 Fusion Max 在 Artificial Analysis Coding Agent Index 得分 60，接近 Claude Code + Opus 5.5 Max，但平均 API 成本约一半、耗时约少 40%。已在 VS Code、Copilot 应用、CLI 与 JetBrains 可用，付费计划限时 30% 模型费用折扣。

Source: https://github.blog/changelog/2026-10-28-route-and-orchestrate-models-with-github-copilot-fusion/

## 4. DOJ inquires into Nvidia’s Hugging Face deal

**美国司法部询问英伟达收购 Hugging Face：关注开源分发控制权**

据 Reuters，美国司法部就英伟达约 129.3 亿美元收购 Hugging Face 向英伟达问询，关注交易是否会损害 AI 市场竞争，以及英伟达是否借此控制开源模型关键分发节点。Hugging Face 托管超 300 万模型、约 1800 万用户；该询问也属于对英伟达收购与销售行为更广泛调查的一部分，交易预计 2027 年上半年完成。

Source: https://www.usnews.com/news/business/articles/2026-10-28/exclusive-us-doj-is-inquiring-about-nvidias-purchase-of-hugging-face-sources-say

## 5. Wabi raises $55M at $1.25B valuation

**Wabi 再融 5500 万美元：估值约 12.5 亿美元，做能生成小应用的个人 AI agent**

据 TechCrunch，面向个人与小组协作的 AI agent 创业公司 Wabi 完成 5500 万美元融资，估值约 12.5 亿美元，由 IVP 领投，a16z、Forerunner、Amazon Alexa Fund 等跟投。产品定位是用 agent 协调日程与任务，并生成个性化小应用，属于消费级个人 agent 赛道的高估值新一轮资本加注。

Source: https://techcrunch.com/2026/10/29/wabi-the-ai-agent-that-builds-mini-apps-now-valued-at-1-25b-after-latest-round/
