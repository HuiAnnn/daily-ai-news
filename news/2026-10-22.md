# Daily AI News — 2026-10-22

> Digest date: 2026-10-22 (Asia/Shanghai). Sources gathered from the past ~24–48 hours.

## 1. OpenAI models and Codex come to Google Cloud Model Garden

**OpenAI 前沿模型与 Codex 进入 Google Cloud Model Garden**

OpenAI 与 Google Cloud 宣布合作，将 GPT-6 Astra、GPT-6.1 Sol、GPT-6 Luna 及 Codex 智能体工作流接入 Model Garden；企业可通过 Marketplace 采购并抵扣 GCP 承诺消费。私有预览已向部分客户开放，后续还将进入 Antigravity 与 Gemini Agent；微软仍是 OpenAI 的主要云合作伙伴。

Source: https://openai.com/index/openai-models-google-cloud

## 2. Anthropic opens Claude Duet research preview

**Anthropic 开放 Claude Duet 研究预览：主动式个人 Agent**

Claude Duet 面向美国 Pro / Max 用户开放 waitlist，基于 Opus 5.5，可发晨间简报、在云端虚拟机持续执行任务，并在发消息、付款、签字或删除前征求批准。支持 iOS、Android 与网页，暂不含 Team / Enterprise；定位对标 Muse 等个人 Agent。

Source: https://claude.com/resources/articles/claude-duet

## 3. Walmart launches Agent Gateway for AI shopping

**沃尔玛推出 Agent Gateway：让合规 AI Agent 代客下单**

沃尔玛发布面向开发者的 Agent Gateway（MCP）测试版，并计划下月上线 Agent Profiles，可为每个 Agent 设支出上限或逐笔审批，同时覆盖 Sam's Club。对比亚马逊封锁外部 Agent，沃尔玛选择「开门+规则」，禁止 Agent 改支付方式或越权操作。

Source: https://www.theverge.com/ai-artificial-intelligence/1015715/walmart-ai-shopping-agents

## 4. Meta says Muse topped 10M users, shopping leads usage

**Meta 称 Muse 超千万用户，购物成主要场景**

Q3 财报电话会上，Zuckerberg 称美加约一个半月内超 1000 万人开通 Muse，约 25% 日活；超四分之一活跃用户通过 Muse 购物，客单价逾 200 美元。公司称短期算力成本很高，但预计一年内效率提升超 10 倍，并构想「Muse 网络」让 Agent 之间协作。

Source: https://techcrunch.com/2026/10/21/meta-says-muse-has-over-10m-users-with-shopping-a-top-activity/

## 5. Critical PHP RCE flaws found with AI assistance

**AI 协助发现 PHP 严重远程代码执行漏洞，影响面极广**

OpenAI（GPT-5.6 Sol）与 Google 旗下 Wiz 分别发现两处可未认证远程代码执行的 PHP 核心漏洞（CVE-2026-109618 / CVE-2026-109619），影响面据称可达互联网约七成站点。PHP 已发布 8.2–8.5 分支修复版，OpenAI、Wiz 与 Cloudflare 参与了协调披露与防护。

Source: https://techcrunch.com/2026/10/21/php-armageddon-openai-googles-wiz-find-ancient-holes-panicking-the-internet/
